How it works
  • A text model writes one self-contained HTML file: the game, its art and its sound effects. openai/gpt-5.4-mini by default, with openai/gpt-5.4-nano, openai/gpt-5.3-codex and z-ai/glm-5.3-flash to pick from.
  • An image model paints the cover (tongyi-mai/z-image-turbo), and a speech model can announce your game (openai/tts-1).
  • Every call goes to the Pollinations API with your own scoped key, so each request is billed to your balance. Nothing is charged until you build.
  • The requests are plain calls to https://gen.pollinations.ai/v1/chat/completions (the game code), https://gen.pollinations.ai/v1/images/generations (cover art) and https://gen.pollinations.ai/v1/audio/speech (announcer) — see api.js.
  • Gamewright is open source, and both the README and this page's footer carry the “Made with pollinations.ai” badge.
  • Games run in a locked-down frame — no network, no access to your account.
  • You sign in with Pollinations Pay, so the app never holds a secret key and never pays on your behalf.
